frieren: автономное приложение-дневник для Android (без Termux)

Что настроено: расписание Пн-Сб, не больше 9 уроков в день; школа по умолчанию
«МБОУ «Школа № 132» г.о.Самара» (адрес asurso.ru); значок: ваша картинка.

ЧТО ЗАГРУЗИТЬ В РЕПОЗИТОРИЙ (путь важен):
  В корень (Add file -> Upload files, можно сразу пачкой):
    package.json, capacitor.config.json, .gitignore, make_icons.py
    любая картинка для значка (например images9.jpg): имя не важно
  www/index.html, www/netschool.js   (Add file -> Create new file, в имени пишите www/...)
  .github/workflows/build-apk.yml    (Create new file, путь пишется целиком)

СБОРКА: вкладка Actions -> Build APK -> Run workflow (или любой коммит в main), 5-8 минут.
Готовый app-debug.apk: раздел Releases. Установите, откройте frieren, введите логин и пароль.
Адрес и школа уже вписаны. Если картинки icon.jpg нет, будет запасной значок, сборка не сломается.

Если вход не проходит: Оформление -> «Диагностика» покажет, где остановился вход (без паролей).
Используйте только свой аккаунт и соблюдайте правила школы. Только Android.
